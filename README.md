# dsh-openrouter-imagen-v2

> **兼容版本：DeepSeek Harness 0.2.x** —— 在 **0.2.0-rc.2** 上开发与实测。
> 声明在 `package.json` 的 `engines.dsh`；判定机制见 [NOTES.md](./NOTES.md)。

给 DeepSeek Harness 接上 OpenRouter 的生图能力，做成一个**独立的工作台**。

> **独立仓库，与 v1 并列。** 它有**自己的**插件 id、设置命名空间、路由前缀和工具名，
> 所以两个可以同时装、互不影响。v1 把生图挂在对话界面上，v2 从侧栏进入、占据中央主视图、**不套用对话界面**。

[English](./README.en.md) · [开发笔记与排错](./NOTES.md)

---

## 介绍

这是一个 DSH 插件，由两半组成：

- **Host 半边** 注册工具 `openrouter_generate_imagen_v2`、同源路由 `/openrouter-imagen-v2/api/*`，
  并维护一份**生成记录**。
- **Client 半边** 注册两个槽位：侧栏入口 `sidebar.panellist` 和中央主视图 `main`。
  点侧栏入口，中央区域整块变成工作台。
- **设置弹窗** —— 密钥、模型、提示词模型都在工作台自己的弹窗里配。
- **随包 skill** `skills/openrouter-imagen-v2/SKILL.md`，教模型「推导画风，不要查表」。

出图有两条路：在工作台里点「生成」，或者让 agent 直接调这个工具。

## 用法

### 工作台

侧栏「插件」组下面点 **图像生成**。两栏，中间的分隔条**可以拖动**调宽度（双击复位）。

- **左栏** 当前大图 + 下面一条历史小图（保留最近 5 张）+ 参数区（高度也能拖）。
- **右栏** 对话：要求 → 提示词 → 出图，全过程可见可改；输入框在这一栏底部。

画幅支持 **12 个比例 + `auto`**，每个都印出数字 —— 方块本身分不出 4:5 和 5:4。
默认值：数量 `1`、质量 `medium`、背景 `auto`、宽高比 `16:9`、分辨率 `1K`。

- **「写提示词后先确认再出图」默认关。** 关着就是点一次「生成」直接出图（提示词仍显示在对话里）；
  打开会在提示词卡片上停一下，等你点「就这样出图」。
- **提示词双模式**：`直接出图`（输入框文字即最终提示词，零额外延迟）与 `让 AI 写提示词`（默认）。
- **模型选择器在输入框下方**，**只作用于这一次出图**，不改设置里的默认值。选过之后会出现「回到默认」，
  顶栏的模型标签也会标出这是本次选择。候选来自设置弹窗的模型清单（最多 16 个）。
- **参考图**（最多 4 张）：点 `+` 选文件、在写作区粘贴、或把图片拖进来都可以，右上角的 `×` 移除。
  它们随这次请求一起发给图像模型，**不经过任何上传**。`让 AI 写提示词` 模式下它们也发给提示词模型，
  写出来的提示词才会**引用**参考图。状态栏会写明 `正在写提示词 · 带 N 张参考图`。
  提示词模型若**没有视觉能力**，会自动退回不传图的写法。
- **种子**在模型那一行的下面、生成按钮正上方。出图后这里会**自动填上本次实际用的种子**（随机抽的也填），
  所以「再点一次生成」就是复现同一张图；旁边的「随机」清空它。

### 设置

右上角的 **设置** 按钮打开一个弹窗，三个页签。**这是配置密钥的唯一入口** —— 工作台有自己的视图，
够不到 DSH 自带的设置页。密钥没配时，这颗按钮是主色的。

- **密钥** —— 填 / 换 / 清除 OpenRouter 密钥，`校验` 按钮当场验证并报额度。
- **模型** —— 一张清单（最多 16 个），**同时管两件事**：有哪些可选、默认用哪个；以及从线上目录挑选。
  标着 **默认** 的那行（绿底）就是实际会用到的那个，其余每行有「设为默认」。
  同一份清单也是对话区选择器的候选池。
- **高级** —— 写提示词的文本模型、保存目录、Provider 排序、附加请求体 JSON。

**两个模型不是一回事**：**图像模型**画图，**提示词模型**写提示词（默认 `google/gemini-2.5-flash`），
后者填成图像模型会失败。

**密钥的处理方式：**

- **已存的密钥不会显示原文。** 弹窗里只显示一个缩略形式（前缀加末四位），够认出「存的是哪一把」，
  但不足以拿来使用。
- **输入框留空 = 保留已存的密钥**，输入了才替换。已经配好密钥时留空是**正常状态**。
- **参数区改完即存，弹窗按 `保存` 才写** —— 密钥和模型在弹窗里是表单，参数区是实时面板。
- **形态不对的密钥在保存时就被挡下**（不以 `sk-or-v1-` 开头、或短得明显不完整），而不是等出图时 401。
  这是**纯本地检查**，不发网络请求。
- **清除是独立的一个按钮**，不会因为清空输入框而误删。
- **「校验」和「拉取模型」可以先用一把还没保存的密钥** —— 只用于那一次请求，不写进设置。
  想先验证再保存，用的就是这个。

### agent 主动生图

除了工作台里的按钮，agent 也能直接调这个工具出图。比如你让它做一个网页、一份文档或一份报告，
它发现缺的正是配图，就会自己去生成。

它有四个参数可用来把图放到该在的位置：

| 参数 | 什么时候填 | 作用 |
| --- | --- | --- |
| `save_dir` | 产物有确定归属时 | 图落到产物自己的目录（相对会话目录），而不是共享的 `generated-images/` |
| `file_name` | 文件名确定时 | 文件名主干；扩展名固定 `.png`，不要自己写进去 |
| `aspect_ratio` | **由 agent 判断** | 网页 hero 要 16:9、头像要 1:1 —— 这是硬约束，prompt 顶不住 |
| `resolution` | 图要当大图用时 | 同上 |

另外这几项你说了算 —— **没点名它就留空**，按工作台里的设置来：
`model`、`quality` 档位、`background`、`seed`。

两条固定规则：

- **一次调用出一张图**，没有「一次出多张」的参数；想要多个版本就多次调用、每次换提示词。
- **格式固定 PNG**，这个参数不可选。

这两条的用处是「生图然后用」这一步是确定的：拿到的路径就是它自己起的那个文件名，
不用在一批按序号排开的候选里再挑一个。

**工作台的手动出图不受影响**：数量、格式、质量在工作台里照旧可选、可存 jpeg/webp、可一次出多张。

### 画幅与尺寸

`resolution` 的 `512 / 1K / 2K / 4K` 是**档位名**，不是输出尺寸。实测一次请求 `2K` + `16:9`，
落地文件是 **1536×864**，不是 2048×1152。按名字推断尺寸会错，而广告位是白名单尺寸
（Google Ads 的 1200×628、300×250、336×280 等），差一个比例就得裁。

工具回执里因此有一行 **`尺寸：1536×864`** —— 这是从图片自己的文件头（PNG 的 IHDR、JPEG 的 SOF、
GIF 的屏幕描述符）读出来的**实际交付像素**。比例与请求不符时，回执会另外加一句明确警告：

```
注意：请求画幅 16:9，实际交付 1200×628（1.91:1）比例不符，投放前需自行裁剪或重出。
```

收到警告就自己决定怎么用 —— 插件只报尺寸，不会替你重出。图已经花钱买了。
**WebP 读不出尺寸**（三种容器变体、14 位打包字段），此时这一行是空的。宽高同样写进生成记录。

### 生成记录

每次生成的**元数据**都会留下来：提示词、实际发出的参数、种子、文件路径、附件 id 和真实交付的宽高
（**不存图片本身**）。记录写在 `~/.dsh/openrouter-imagen-v2/history.json`，**重启后仍在**，
**最多 60 条**，最新的在前 —— 工作台的「最近 5 张」和「用同样参数再出」都读它。

### 已知限制

- **「让 AI 写提示词」不共享对话上下文。** 它是一次独立的文本模型调用（不是模板拼接），
  但不会带上你在对话里已经聊过的内容。
- **参考图是一次性的**：它们跟着那一次请求走，不写进历史记录，也不随「用同样参数再出」重放。
  重新出图要重新挂上去。
- **工作台的对话栏是它自己的记录**，不读也不写 DSH 的会话消息流。这样工作台才能独立于对话存在。
- **图片显示尺寸由工作台自己决定**（大图自适应、历史小图 54px）。

### 安全边界

- **密钥不外泄**：任何设置读取接口都不返回它，只给可辨认但不可用的缩略形式。
- **「校验」和「拉取模型」用的候选密钥不落盘**，只用于那一次请求。
- **参考图限制在会话工作目录内** —— 这些字节会发往第三方，越界路径会被直接拒绝。
- **落盘目录同样受限**：`save_dir` 越出会话工作目录会**报错**，而不是换个地方存。
- **工具参数是封闭的**：未声明的键会被拒绝，不会混进请求体。
- **附加请求体 JSON 不能越权**：覆盖不了 `model` / `prompt` / `input_references`。
- **取消会被观测**：取消一轮对话会真的放弃这次付费请求。

## 安装

标准通道是官方 CLI：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile desktop add X:\github\dsh-openrouter-imagen-v2
```

装完**重启 DSH**，刷新页面，侧栏「插件」组下面会出现 **图像生成**。

<details>
<summary>手动挂载（不走 CLI）</summary>

两步缺一不可：

1. 建一个指向包目录的 junction（**必须用 junction 而不是符号链接**：ESM 按真实路径解析依赖，
   符号链接会让包内的 `import '@deepseek-ai/...'` 找不到）：

   ```powershell
   $link = 'C:\Users\WR\.dsh\profiles\desktop\node_modules\dsh-openrouter-imagen-v2'
   New-Item -ItemType Junction -Path $link -Target 'X:\github\dsh-openrouter-imagen-v2'
   ```

2. 在 **`~/.dsh/profiles/desktop/cordis.patch.yml`** 里插入挂载行：

   ```yaml
   - insert:
       - id: openrouter-imagen-v2
         name: 'dsh-openrouter-imagen-v2'
   ```

3. 在本包目录里跑一次 `npm install`。

4. **重启 DSH**。

</details>

**不要同时用两条通道**：同一个 `(kind, path)` 的路由会被注册两次，整个插件树在启动时失败。

---

## 卸载

删掉 profile 里的 junction（或用 CLI 装的包）、从 `~/.dsh/profiles/desktop/cordis.patch.yml` 移除那条
`insert` 行，然后**重启 DSH**。

`~/.dsh/settings.yaml` 里的 `openrouter-imagen-v2` 段（密钥和设置）与
`~/.dsh/openrouter-imagen-v2/` 目录（生成记录）可以一并删除。已经生成到磁盘上的图片不会被动到，
自己按需清理。
